## Менеджер баланса

Консольное приложение на Go для управления балансом пользователя с базовыми банковскими операциями.

## Зависимости

- Go 1.26+

## Установка

```bash
git clone https://github.com/kreslokatalka/UBM
cd UBM
go run project.go
```
## Описение версии
Созданы структуры Transaction и PaymentSyste, реализованы методы ProcessingTransaction, AddUser и AddTransaction для PaymentSystem
