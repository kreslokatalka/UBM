## Менеджер баланса

Консольное приложение на Go для управления балансом пользователя с базовыми банковскими операциями.

## Зависимости

- Go 1.26+

## Установка

```bash
git clone https://github.com/kreslokatalka/UBM
cd UBM
go run project.go
```
## Описание версии
Создана функция worker для конкурентной обработки транзакций и функции rand_user, create_trans и create_user для упрощенного тестирования
