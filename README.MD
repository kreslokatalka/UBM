## Менеджер баланса

Консольное приложение на Go для управления балансом пользователя с базовыми банковскими операциями.

## Зависимости

- Go 1.26+

## Установка

```bash
git clone https://github.com/kreslokatalka/UBM
cd UBM
go run project.go
```
## Описание версии
Были создана структура User имеющая три поля ID, Name и Balance, и 2 метода withdraw и deposit для изменения баланса
